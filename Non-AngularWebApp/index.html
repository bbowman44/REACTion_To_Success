Welcome to the Best Page Ever

This is a webpage designed to be for me to learn front end development. I am familiar with back end development in .net as well as other strongly typed languages like C++ or Java.

I am excited to learn new technologies and expand my skill set in front end development. This webpage will serve as a platform for me to showcase my work and share my knowledge with others.

Web Design Tasks To Complete:

  • Be sure to set up a sizing for mobile (responsive design) that changes the headers into icons when below 1000px and also changes the side bar into a drop down menu that can be accessed with a hamburger icon.
  • Design a light mode for fun that changes the colors on the page to be light instead of dark.
  • 7 Implement on hover effects for links and header tabs to make the page more interactive and visually appealing.
  • Create another webpage to link to that can be for adding items to a shopping list and saving them in local storage. This will be a fun project to learn about local storage and how to manipulate it with JavaScript.
  • Build an image carousel from scratch using JavaScript to learn about DOM manipulation and event handling. This will be a fun project to showcase some of my favorite images and also learn about how to create interactive elements on a webpage.
  • build a button that contacts a hello world endpoint that is already created and will display the response on the page. This will also implement the two native implementations of api calls, fetch and XMLHttpRequest to compare the two and learn about how to make api calls in JavaScript.
  • Also build another button that calls an external api that I did not create, like a third party weather api or something simple to learn about using other peoples external apis.
  • build a reusable modal without a framework or anything similar like a tooltip, toast notification, tabs, accordian, sidebar hamburger menu thats responsive with mobile.
  • build form handling with validation and error messages to learn about how to create forms and handle user input on a webpage. These need to include required fields, email validation, live validation, error messages, success messages, button disable loading states, saving cache or draft of form to continue later, etc.
  • build a rich text editor from scratch to learn about how to create a complex interactive element on a webpage. This will be a fun project to learn about contenteditable and how to manipulate it with JavaScript.
  • Create a CRUD based page or app inside the webpage to expand on fundamentals such as how to do , create, read, update, delete.
  • In addition to above, create a filter, search, and sort for the crud page with table or other information that can be manipulated in those ways to learn about how to create dynamic and interactive tables or lists on a webpage.
  • Create mini layout library similar to bootstrap or tailwind that has a set of predefined classes for spacing, flexbox, grid, etc. to learn about how to create a design system and reusable styles for a webpage.
  • Expand on the search bar with live searching, debouncing, api calls, loading indicators, dropdown results, etc. to learn about how to create a complex and interactive search bar on a webpage.
  • Create a drag and drop interface to learn about how to create interactive elements on a webpage that can be moved around and manipulated with the mouse.(making my own kanban or agile board with backlog would be neat)
